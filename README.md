# CIS 613 - Software Testing

This repository contains course contents, and assignments for **CIS 613: Software Testing**.

## Course Overview

Discussion of the major techniques of software testing: software technical reviews, software testing techniques, proofs
of correctness, and simulation/prototyping. Concludes with guidelines on organizational implications of software
verification and validation activities.

## Tools & Technologies

- Programming languages: Java, Python
- Topics: Unit Testing Framework, Symbolic Execution, Graph Theory, Discrete Math, Boundary Value Testing, Equivalence
  Class Testing, Path and Coverage Testing, MCDC Testing, Decision Table Based Testing, Dataflow Testing, Testing
  Ethics, Lifecycle Based Testing, Model Based Testing, Mutation Testing, Integration Testing, System Testing,
  Metamorphic Testing, Model Checking, Technical Review, Exploratory Testing, Genetic Algorithms
- Tools: JUnit, PITest, unittest, pytest, mutmut, Java Path Finder (JPF)
